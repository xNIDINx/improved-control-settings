# Улучшенные настройки управления

`nidin.improved_control_settings` — мод для «Мира танков»: отдельные клавиши снаряжения для **Стального охотника, Натиска и Линии фронта** и выбор способа настройки чувствительности мыши.

[Скачать мод](https://github.com/xNIDINx/improved-control-settings/releases/latest)

## Установка

Закройте игру и скопируйте файл `.mtmod` из релиза без распаковки в `<папка игры>/mods/<версия клиента>/`. Оставьте только одну версию мода.

Если установлены прежние отдельные моды `nidin.mouse_sensitivity` или `nidin.mode_control_profiles`, уберите их из этой папки: их возможности уже включены в этот мод.

Для выбора режима чувствительности и включения/выключения мода нужна **«Настройка модификаций» (ModsSettingsAPI)**. Без неё доступны профили управления и точный цифровой ввод чувствительности по умолчанию.

## Управление

Откройте **Настройки → Управление**.

- **Профили режимов.** Выберите вкладку режима и назначьте клавиши снаряжения. В бою соответствующий профиль включается автоматически. Изменения одного профиля не затрагивают остальные; случайные бои и другие режимы используют общие клавиши.
- **Чувствительность мыши.** Настраивается на вкладке «Общие настройки» и остаётся общей для всех режимов. По умолчанию доступны точные поля под ползунками. Tab переключает поля сверху вниз, Shift+Tab — обратно; после последнего поля Tab переводит фокус на крестик окна.
- **Сохранение.** Нажмите «Применить» или «ОК», чтобы сохранить изменения. «Отмена» отменяет неприменённые изменения.

## Настройки мода

В **«Настройке модификаций» → «Улучшенные настройки управления»** выберите один режим чувствительности:

- **Точная цифровая из preference** — ручной ввод игровых значений чувствительности с шестью знаками после запятой в полях под ползунками. Выбрана по умолчанию.
- **Упрощённая от 0 до 100** — справа отображается положение ползунка от 0 до 100. Для изменения чувствительности перемещайте ползунок.
- **Стандартный** — штатные ползунки без дополнительных чисел. Профили управления по режимам продолжают работать.

Нажмите «Применить» или «ОК», затем полностью закройте и снова откройте настройки игры, чтобы отобразился выбранный режим. Переключение вида не меняет значения чувствительности.

Кнопка в правом верхнем углу блока полностью включает или выключает мод после «Применить»/«ОК». При выключении убираются дополнения к чувствительности и вкладки профилей, возвращаются общие назначения клавиш. Сохранённые профили и выбранный режим остаются для повторного включения. По умолчанию мод включён.
